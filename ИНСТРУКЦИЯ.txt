=====================================================================
          CYDIA REPO BUILDER — ПОЛНАЯ ИНСТРУКЦИЯ
=====================================================================

Эта программа автоматически создаёт ваш собственный репозиторий 
для джейлбрейкнутых iOS-устройств (Cydia, Sileo, Zebra), генерирует
каталоги пакетов (Packages, Packages.bz2, Release), красивую 
веб-витрину и сама загружает всё на бесплатный хостинг GitHub Pages.

---------------------------------------------------------------------
ТРЕБОВАНИЯ (ЧТО ДОЛЖНО БЫТЬ УСТАНОВЛЕНО НА КОМПЬЮТЕРЕ):
---------------------------------------------------------------------
1. Python 3 (https://www.python.org/downloads/)
   ВАЖНО: При установке ОБЯЗАТЕЛЬНО поставьте галочку 
   [x] "Add python.exe to PATH" внизу первого окна установщика!
   
2. Git (https://git-scm.com/downloads)
   Необходим для автоматической отправки файлов на GitHub.

---------------------------------------------------------------------
ПОШАГОВОЕ СОЗДАНИЕ РЕПОЗИТОРИЯ С НУЛЯ:
---------------------------------------------------------------------

ШАГ 1. Создайте пустой репозиторий на GitHub:
  1. Перейдите по ссылке: https://github.com/new
  2. В поле «Repository name» напишите любое имя (например: cydia-repo).
  3. Убедитесь, что выбран тип «Public» (Публичный).
  4. ВНИМАНИЕ: НЕ ставьте галочки у README, .gitignore или License!
     Репозиторий должен быть полностью пустым.
  5. Нажмите зелёную кнопку «Create repository».
  6. Скопируйте ссылку на репозиторий из адресной строки или блока Quick Setup
     (пример ссылки: https://github.com/ваш_ник/cydia-repo).

ШАГ 2. Положите ваши твики:
  1. Скопируйте файлы твиков (.deb) в папку «debs».
  (Если у вас пока нет файлов .deb — ничего страшного! Репозиторий можно 
   создать и пустым, а твики закинуть в любой момент позже).

ШАГ 3. Запустите сборщик:
  1. Дважды кликните по файлу «start.bat».
  2. Вставьте скопированную ссылку на GitHub (нажмите правую кнопку мыши в окне)
     и нажмите Enter.
  3. Введите название и краткое описание репозитория (или просто жмите Enter, 
     чтобы оставить стандартные значения).
  4. Скрипт сделает всё сам:
     - Извлечёт данные из всех .deb (название, версию, автора, описание).
     - Рассчитает контрольные суммы MD5 и SHA256.
     - Создаст индексы Packages, Packages.bz2, Packages.gz, Release.
     - Создаст сайт index.html с кнопками быстрой установки.
     - Отправит всё на ваш GitHub.

ШАГ 4. Включите сайт GitHub Pages (делается один раз):
  1. В вашем репозитории на GitHub откройте вкладку:
     Settings -> Pages (или перейдите по ссылке из консоли).
  2. В блоке «Build and deployment»:
     - Source: Deploy from a branch
     - Branch: выберите ветку «main», папку «/ (root)»
  3. Нажмите кнопку «Save».
  (Через 1-2 минуты сайт и репозиторий начнут работать!)

---------------------------------------------------------------------
КАК ДОБАВИТЬ РЕПОЗИТОРИЙ НА IPHONE / IPAD:
---------------------------------------------------------------------
Адрес вашего репозитория будет выглядеть так:
https://ваш_ник.github.io/имя_репозитория/

СПОСОБ 1 (Самый удобный — через Safari):
  1. Откройте ссылку на ваш репозиторий в браузере Safari на iPhone/iPad.
  2. На открывшейся странице нажмите большую кнопку:
     «Добавить в Cydia» или «Добавить в Sileo».
  3. Cydia откроется сама и предложит установить источник.

СПОСОБ 2 (Вручную в Cydia):
  1. Откройте Cydia на устройстве.
  2. В нижней панели выберите вкладку «Источники» (Sources).
  3. В правом верхнем углу нажмите «Правка» (Edit), затем слева — «Добавить» (Add).
  4. В появившемся окне введите адрес репозитория:
     https://ваш_ник.github.io/имя_репозитория/
  5. Нажмите «Добавить источник» и дождитесь загрузки пакетов.

СПОСОБ 3 (В Sileo или Zebra):
  - Sileo: Источники -> плюс (+) в правом верхнем углу -> вставить ссылку.
  - Zebra: Sources -> плюс (+) -> вставить ссылку.

---------------------------------------------------------------------
КАК ДОБАВЛЯТЬ НОВЫЕ ТВКИ ИЛИ ОБНОВЛЯТЬ ИХ В БУДУЩЕМ:
---------------------------------------------------------------------
1. Скопируйте новые или обновлённые .deb файлы в папку «debs».
2. Снова запустите «start.bat».
3. Нажмите Enter (скрипт запоминает ваши предыдущие настройки).
4. Скрипт пересоберёт индексы и сам отправит обновление на GitHub.
На устройствах пользователей новые твики появятся при следующем 
обновлении источников в Cydia.

---------------------------------------------------------------------
КАК УДАЛИТЬ ТВК ИЗ РЕПОЗИТОРИЯ:
---------------------------------------------------------------------
1. Просто удалите ненужный .deb файл из папки «debs».
2. Запустите «start.bat» — скрипт удалит твик из индексов и обновит GitHub.

---------------------------------------------------------------------
ЧАСТЫЕ ВОПРОСЫ И ОШИБКИ:
---------------------------------------------------------------------
Вопрос: При выполнении git push появляется ошибка или просит пароль?
Ответ:  Git на компьютере должен быть авторизован в вашем аккаунте GitHub.
        Обычно при первом push Windows сама открывает всплывающее окно 
        «Sign in with your browser». Просто нажмите Sign in.

Вопрос: В Cydia пишет «Не удалось найти данный репозиторий» (Error 404)?
Ответ:  1. Проверьте, включили ли вы GitHub Pages (Шаг 4 выше).
        2. После включения GitHub Pages требуется 1-2 минуты, чтобы сервера
           GitHub активировали сайт. Подождите пару минут и попробуйте снова.
        3. Убедитесь, что в конце ссылки есть слэш: .../cydia-repo/

Вопрос: Можно ли изменить название или описание репозитория?
Ответ:  Да, файл «config.json» хранит ваши настройки. При следующем запуске
        «start.bat» скрипт спросит, хотите ли вы оставить старые или ввести новые.
