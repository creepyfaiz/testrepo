=====================================================================
          CYDIA REPO BUILDER — ИНСТРУКЦИЯ ПО ЗАПУСКУ
=====================================================================

ЧТО ДОЛЖНО БЫТЬ УСТАНОВЛЕНО НА КОМПЬЮТЕРЕ:
1. Python (https://www.python.org/downloads/)
   ВАЖНО: При установке ОБЯЗАТЕЛЬНО поставьте галочку 
   "Add python.exe to PATH" внизу окна установщика!
2. Git (https://git-scm.com/) — для отправки репозитория на GitHub.

---------------------------------------------------------------------
ПОШАГОВАЯ ИНСТРУКЦИЯ:
---------------------------------------------------------------------

ШАГ 1. Создайте репозиторий на GitHub
  1. Зайдите на https://github.com/new
  2. В поле «Repository name» укажите имя (например: cydia-repo).
  3. Выберите «Public».
  4. ВАЖНО: НЕ ставьте галочки у README, .gitignore или License!
     Репозиторий должен быть полностью пустым.
  5. Нажмите «Create repository».
  6. Скопируйте ссылку на ваш репозиторий:
     (например: https://github.com/ваш_ник/cydia-repo)

ШАГ 2. Добавьте файлы твиков
  1. Скопируйте ваши твики (.deb) в папку «debs».
  (Если твиков пока нет — ничего страшного, можно запустить и без них, 
   а добавить позже).

ШАГ 3. Запустите сборщик
  1. Дважды кликните по «start.bat».
  2. Вставьте скопированную ссылку на GitHub (ПКМ в окне консоли) и нажмите Enter.
  3. Введите название репозитория и описание (или просто жмите Enter 
     для значений по умолчанию).
  4. Скрипт сам:
     - Прочитает метаданные из всех .deb пакетов.
     - Создаст индексы Packages, Packages.bz2, Packages.gz, Release.
     - Сгенерирует красивый сайт index.html с кнопкой «Добавить в Cydia».
     - Отправит всё на ваш GitHub.

ШАГ 4. Включите сайт GitHub Pages (делается один раз):
  1. Перейдите в настройки репозитория: Settings -> Pages
     (или по ссылке, которую скрипт напишет в конце работы).
  2. В блоке «Build and deployment» в списке Branch выберите «main» 
     и нажмите кнопку «Save».

---------------------------------------------------------------------
ГОТОВО!
Через 1-2 минуты ваш репозиторий станет доступен.
Ссылка для Cydia: https://ваш_ник.github.io/имя_репозитория/
